# 📦 Node-RED AlephScript SDK - Installation Process Documentation

## Overview

Este documento describe el proceso completo de instalación y distribución del paquete `node-red-alephscript-sdk` que contiene **dos librerías independientes**:

1. **`node-red-contrib-alephscript`** - Node-RED contrib compatible con Node-RED latest
2. **`node-red-gamify-ui`** - App Angular que implementa patrón GamificationUI para se publicda en state-machine-mcp-driver y servida en un directorio public para webapps.

El proceso sigue el pattern establecido por `threejs-gamify-ui`.

## 🏗️ Dual-Library Architecture Pattern

### Package Structure
```
node-red-alephscript-sdk/
├── package.json                          # Main package with dual libraries
├── scripts/
│   └── postinstall.cjs                  # Installation script for both libraries
├── projects/
│   ├── node-red-contrib-alephscript/     # LIBRERÍA 1: Node-RED contrib package
│   │   ├── dist/                         # Built contrib nodes
│   │   ├── src/                         # Node-RED node implementations
│   │   └── package.json
│   └── node-red-gamify-ui/              # LIBRERÍA 2: Angular Web UI
│       ├── dist/                         # Built Angular app
│       ├── src/app/                     # Angular source (GamificationUI pattern)
│       └── package.json
```

Consumers of node-red-gamify-ui after postinsall structure:

```
└── public_templates/                     # NOT included in package
    |
    └── node-red-gamify-ui/              # Generated by postinstall (Angular UI)
```


## 🔄 Dual-Library Installation Flow

### 1. Package Build Process (`npm run build:package`)

```bash
# Build both independent libraries
npm run build:contrib     # → projects/node-red-contrib-alephscript/dist/
npm run build:webapp      # → projects/node-red-gamify-ui/dist/
npm pack                  # → node-red-alephscript-sdk-1.0.0.tgz
```

### 2. Consumer Installation (`npm install node-red-alephscript-sdk`)

Cuando un proyecto instala el package:

```bash
npm install node-red-alephscript-sdk
# Triggers automatically:
node scripts/postinstall.cjs
```

### 3. PostInstall Script Process (Dual-Library Distribution)

```javascript
// scripts/postinstall.cjs
function main() {
  // 1. Find consumer's project root
  const projectRoot = findProjectRoot();
  
  // 2A. Source: node-red-contrib-alephscript (Node-RED contrib nodes)
  const sourceContribDir = path.join(__dirname, '..', 'projects', 'node-red-contrib-alephscript', 'dist');
  const targetContribDir = path.join(projectRoot, 'public_templates', 'node-red-contrib-alephscript');
  
  // 2B. Source: node-red-gamify-ui (Angular GamificationUI app)
  const sourceWebUIDir = path.join(__dirname, '..', 'projects', 'node-red-gamify-ui', 'dist');
  const targetWebUIDir = path.join(projectRoot, 'public_templates', 'node-red-gamify-ui');
  
  // 3A. Copy Node-RED contrib artifacts
  if (fs.existsSync(sourceContribDir)) {
    copyDirectory(sourceContribDir, targetContribDir);
    console.log('✅ Node-RED AlephScript contrib nodes installed to public_templates/node-red-contrib-alephscript');
  }
  
  // 3B. Copy Angular build artifacts
  if (fs.existsSync(sourceWebUIDir)) {
    copyDirectory(sourceWebUIDir, targetWebUIDir);
    console.log('✅ AlephScript GamificationUI Web App installed to public_templates/node-red-gamify-ui');
  }
}
```

### 3. PostInstall Script Process

```javascript
// scripts/postinstall.cjs
function main() {
  // 1. Find consumer's project root
  const projectRoot = findProjectRoot();
  
  // 2. Source: Package's built Angular app
  const sourceWebUIDir = path.join(__dirname, '..', 'projects', 'node-red-gamify-ui', 'dist');
  
  // 3. Target: Consumer's public_templates
  const targetDir = path.join(projectRoot, 'public_templates', 'node-red-gamify-ui');
  
  // 4. Copy Angular build artifacts
  if (fs.existsSync(sourceWebUIDir)) {
    copyDirectory(sourceWebUIDir, targetDir);

  }
}
```

## ⚠️ Critical Requirements

1. **Angular Build**: Must output to `projects/node-red-gamify-ui/dist/`
2. **PostInstall**: Must copy to consumer's `public_templates/node-red-gamify-ui/`
3. **UIFactory**: Must support new type `"node-red-gamify-ui"`
4. **Configuration**: Must support `provideTemplate` option
5. **AlephScript Protocol**: Must implement full protocol stack
6. **3-Channel Integration**: Must route App/Sys/UI channels properly

## 🚀 Usage After Installation

1. Consumer installs package: `npm install node-red-alephscript-sdk`
2. PostInstall automatically copies Angular app to `public_templates/node-red-gamify-ui/`
3. Consumer configures in `xplus1-config.json` with `type: "node-red-gamify-ui"`
4. MultiUIGameManager loads and serves from `public_templates/node-red-gamify-ui/`
5. Angular app provides Node-RED management interface with AlephScript integration

This pattern ensures seamless distribution and integration following the established GamificationUI ecosystem patterns.
